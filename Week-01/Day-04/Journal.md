# Day 04 - Working with Log Files

## Objective
Learn how Linux commands are used to inspect, analyze, and monitor log files.

## Topics Covered
- Viewing files
- Reading log files efficiently
- Monitoring logs in real time
- File identification

## Commands Practiced
- `cat`
- `head`
- `tail`
- `tail -f`
- `wc`
- `nl`
- `file`

## What I Learned
- `cat` is useful for small files but not practical for large logs.
- `head` and `tail` provide quick access to relevant portions of a file.
- `tail -f` enables real-time log monitoring.
- The `file` command identifies files based on their content rather than their extension.

## Reflection
Today's exercises demonstrated how Linux commands are applied during log analysis, moving beyond simple command usage into practical investigation.
