# Day 02 - File Operations & Permissions

## Objective
Practice advanced file operations and understand the role of permissions in Linux.

## Topics Covered
- Recursive copy
- Verbose command execution
- File permissions
- Root privileges
- Using `sudo`

## Commands Practiced
- `cp -r`
- `cp -rv`
- `mv`
- `chmod`
- `sudo`

## What I Learned
- Recursive operations are required when working with directories.
- Verbose mode helps verify command execution.
- Linux permissions protect the operating system from unauthorized modifications.

## Reflection
Today's session highlighted that understanding permissions is just as important as knowing the commands themselves.
