# Day 03 - Reinforcement Through Practice

## Objective
Improve confidence and accuracy by revisiting previously learned Linux commands.

## Topics Covered
- File operations
- Directory navigation
- Command repetition
- Linux workflow

## Commands Practiced
- `pwd`
- `ls`
- `cd`
- `mkdir`
- `touch`
- `cp`
- `mv`
- `rm`
- `rmdir`
- `chmod`
- `sudo`

## What I Learned
- Consistent practice improves command recall and confidence.
- Repetition helps identify mistakes and develop faster problem-solving skills.
- Understanding commands is more valuable than memorizing them.

## Reflection
Today's focus was on strengthening existing knowledge instead of learning new commands, ensuring a solid foundation for upcoming security-focused exercises.
